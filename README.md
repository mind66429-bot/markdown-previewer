# Markdown Previewer

A minimalist browser-based live Markdown editor and previewer with instant rendering, word count, and HTML export.

## Features

- Split-pane live Markdown editing and rendered preview
- Supports headings, bold/italic text, code blocks, lists, and blockquotes
- Live character and word count badge
- Zero external frameworks required

## Getting Started

Open `index.html` in any modern web browser.
